# Project Planning Documents

Source planning documents for the AI Personal Wardrobe Assistant, in reading order.

| # | File | Covers |
|---|------|--------|
| 01 | `01_Concept_Idea.docx` | Product vision, v1 scope, core flows, risks. |
| 02 | `02_PRD.docx` | Full product requirements: goals, screens, functional requirements, user stories/acceptance criteria, data model overview, NFRs, metrics/risks, milestones. |
| 03 | `03_TRD.docx` | Technology stack, architecture, detailed data model, recommendation engine pipeline, API design, offline design, security/privacy, implementation phases. |
| 04 | `04_System_Design_Document.docx` (Group A) | Consolidated architecture, relational schema, REST API contract, and baseline PostgreSQL DDL. Source of truth for entity/endpoint naming. |
| 05 | `05_Product_Interface_Design.docx` (Group B) | Screen inventory, UX rules, flows, and states (empty/loading/error/offline) across all major screens. |
| 06 | `06_Diagram_Pack.docx` (Group C) | 8 diagrams: high-level architecture, user flow, UML use case, UML class, UML sequence, DFD Level 0/1/2. |
| 07 | `07_Build_Execution_Pack.docx` (Group D) | Execution guidance: build starter pack, roadmap, task breakdown, and AI coding agent prompt guidance summary. |

See `../IMPLEMENTATION_PLAN.md` at the repo root for the build-ready plan synthesized from these documents.
